# poradnik-git
Poradnik Git i GitHub
1. Czym jest Git?

Git to system kontroli wersji, który pozwala śledzić zmiany w plikach i wracać do wcześniejszych wersji.

2. Czym jest GitHub?

GitHub to internetowa platforma do przechowywania repozytoriów Git i współpracy nad projektami.

3. Podstawowe komendy Git
git --version – sprawdza wersję Gita.
git status – pokazuje stan plików.
git add . – przygotowuje zmiany do zapisania.
git commit -m "opis" – zapisuje zmiany w historii.
git push – wysyła zmiany na GitHuba.
git pull – pobiera i integruje zmiany ze zdalnego repozytorium.
4. Podsumowanie

Git i GitHub pomagają kontrolować zmiany w plikach, przechowywać kod i współpracować z innymi osobami.
